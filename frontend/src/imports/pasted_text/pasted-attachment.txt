# Penpot AI Prompt – Official Ninja Era Website (Complete Multi-Page UI/UX Design System)

Design a modern, premium-quality, responsive gaming website for **Ninja Era** using **Material Design 3** principles. Every component must be based on Material UI (MUI), and every icon must come from the Material UI Icons library. The visual style should combine modern MMORPG aesthetics with elegant anime-inspired ninja elements. The overall design should feel immersive, clean, highly usable, and suitable for both desktop and mobile devices.

Use **Light Mode as the default** while also designing a complete **Dark Mode** version using the same component system.

Create every page in the same design system using an 8px spacing grid, rounded corners (12–20px), subtle shadows, soft glassmorphism where appropriate, smooth animations, accessible typography, and excellent UX hierarchy.

The website must include the following pages:

* Home (Landing Page)
* About
* Resources
* Teamwork
* Contact
* Login
* Sign Up
* Messages
* Profile
